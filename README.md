## 📖 Descripción

Este proyecto es una **página web estática** diseñada como material didáctico para la cátedra **Ingeniería de Requerimientos I** (Eje Temático N.° 2 — Semana 6). Su objetivo es enseñar a los estudiantes:

- 🧠 **Por qué** modelar procesos (claridad, análisis, documentación, comunicación).
- 📊 **Qué tipos de diagramas** existen y cuándo usar cada uno (Flujo, DFD, UML Actividades, BPMN).
- 🛠️ **Qué son las herramientas CASE** y cuáles son las más utilizadas (draw.io, Mermaid + IA, Jira, Figma/Uizard).
- 🎯 **Cómo aplicar** todo esto en un desafío práctico con escenarios reales.

---

## ✨ Características

- 🎨 **Diseño moderno** con fondo animado, gradientes y tipografía *Space Grotesk*.
- 🃏 **Tarjetas expandibles** con diagramas visuales de cada notación (Flujo, DFD, UML, BPMN).
- 📐 **Sección comparativa** "¿Cuál usar?" que ayuda a decidir según el tipo de proceso.
- 🧰 **Introducción a herramientas CASE** con descripción y uso de cada una.
- 🎯 **3 escenarios prácticos** reutilizados de la clase anterior (Turnos Médicos, Delivery, Inventario).
- 🗺️ **Roadmap de 5 pasos** con instrucciones paso a paso para modelar un proceso real.
- 🤖 **Alternativa con IA**: uso de Mermaid + LLM para generar diagramas a partir de texto.
- 📱 **100% responsive** — funciona en desktop, tablet y móvil.

## 📚 Contenido Didáctico

### Tipos de Diagramas Cubiertos

| Diagrama | Icono | Ideal para... |
|----------|-------|---------------|
| **Diagrama de Flujo** | 📊 | Procesos simples y públicos no técnicos |
| **DFD** | 🔄 | Mostrar cómo viajan los datos en un sistema |
| **UML Actividades** | 🎯 | Múltiples actores con responsabilidades (swimlanes) |
| **BPMN** | 📋 | Procesos de negocio con notación rigurosa |

### Herramientas CASE Mencionadas

- [draw.io](https://app.diagrams.net/) — Diagramas de flujo, UML, DFD (herramienta principal de la clase)
- [Mermaid Live](https://mermaid.live/) — Diagramas generados a partir de texto (combinable con IA)
- [Jira](https://www.atlassian.com/software/jira/free) — Gestión de proyectos
- [Figma](https://www.figma.com/) / [Uizard](https://uizard.io/) — Prototipos de interfaz

### Escenarios del Desafío

- 🏥 **Sistema de Turnos Médicos** → proceso completo de solicitud y confirmación
- 🚚 **App de Delivery "Ya Llego"** → flujo de un pedido hasta la entrega
- 📦 **Sistema de Inventario "StockSeguro"** → actualización de stock al recibir mercadería

## 🎯 Objetivos de Aprendizaje

Al finalizar el uso de este material, el estudiante será capaz de:

1. ✅ Explicar la importancia del modelado de procesos en ingeniería de software.
2. ✅ Diferenciar los tipos de diagramas (Flujo, DFD, UML, BPMN) y elegir el adecuado.
3. ✅ Construir diagramas profesionales usando herramientas CASE como draw.io.
4. ✅ Aplicar IA (Mermaid + LLM) para generar diagramas a partir de descripciones textuales.
5. ✅ Justificar decisiones de modelado ante un público técnico y no técnico.
